Blink is sleeping.

This planning agent was built in the open for Google's All Things Agentic Hackathon: Gemini and the ADK deciding what to do, deterministic code deciding what is true, and a calendar it could never lie about.

The hackathon ended, and Blink has earned its rest. No plans are being made here for now, and nothing you type is being heard.

The code is awake at github.com/cozyCodr/blink — 987 offline tests and all.
